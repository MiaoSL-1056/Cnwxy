# 陈晓远档案终端

基于新拟物风格（Neumorphism）构建的个人档案与交互式 UI 控件展示页面，使用原生 HTML、CSS 和 JavaScript 开发。

## 项目简介

本项目是一个单文件网页应用，作为个人在线名片与 UI 控件实验室。页面采用新拟物设计语言，通过细腻的阴影、高光与过渡动画，模拟真实的物理按键触感。页面包含大量常用的前端交互组件，具备完整的响应式布局。

## 技术栈

- HTML5
- CSS3 (Flexbox, Grid, CSS Variables)
- JavaScript (原生)

## 设计规范

- **设计风格**：新拟物（Neumorphism）
- **色彩体系**：极简黑白灰基调，以 `#E30613` 红色作为强调色
- **字体排版**：Inter 字体，流式大字号排版
- **动画曲线**：内置多种 cubic-bezier 缓动函数

## 功能组件

页面集成了以下 14 类交互组件：

1. **轻提示 (Toast)**：底部弹出式反馈
2. **开关与选择**：状态开关、自定义复选框与单选框
3. **输入框**：具备内阴影聚焦动效的只读文本框
4. **滑动与进度**：滑块、进度条与实时读数联动
5. **标签与徽章**：可切换选中状态的标签与静态徽章
6. **导航与折叠**：标签页切换面板、手风琴折叠信息
7. **卡片与列表**：具有按压回弹效果的卡片和悬浮反馈的列表项
8. **加载动画**：环形加载器与脉冲圆点动画
9. **步进器与分段控件**：加减步进器与分段视图切换器
10. **悬浮提示 (Tooltip)**：适配桌面端悬停和移动端点击
11. **模态框预览**：按钮风格确认弹窗
12. **星级评分**：1-5 星打分功能
13. **分页导航**：带激活态的页码切换
